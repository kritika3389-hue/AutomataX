Formal Proof by Pumping Lemma

FLA Subject Reference & Theory Guide

1. Pushdown Automata (PDA)

A Pushdown Automaton is a 7-tuple: M = (Q, Σ, Γ, δ, q₀, Z₀, F)

  • Q: Finite set of states
  • Σ: Finite set of input symbols (input alphabet)
  • Γ: Finite set of stack symbols (stack alphabet)
  • δ: Transition function Q × (Σ ∪ {ε}) × Γ → P(Q × Γ*)
  • q₀ ∈ Q: Start state
  • Z₀ ∈ Γ: Initial stack symbol
  • F ⊆ Q: Set of accepting / final states

2. Instantaneous Description (ID)

The configuration of a PDA at any step is denoted by a triplet (q, w, γ), where:

  • q: Current state
  • w: Remaining unread portion of the input string
  • γ: Complete contents of the pushdown stack (from top to bottom)

A transition is denoted by the turnstile symbol ⊢.

3. Pumping Lemma for Context-Free Languages

If L is context-free, there exists p ≥ 1 such that any string s ∈ L with |s| ≥ p can be written as s = uvwxy where:

  • |vwx| ≤ p (The window vwx spans at most p characters)
  • |vx| ≥ 1 (At least one of v or x is non-empty)
  • ∀ i ≥ 0, uvⁱwxⁱy ∈ L (Pumping v and x must stay inside L)

To prove a language is not context-free, we show that every possible partition violating this condition leads to a contradiction for some i (usually i = 2 or i = 0).
